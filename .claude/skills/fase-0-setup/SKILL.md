Kerjakan Fase 0 sesuai `docs/phases/phase-0.md`.

1. Jalankan `make test`. Jika gagal, bantu perbaiki setup.
2. Bantu isi `docs/research-charter.md` per bagian. Beri 1–3 usulan dengan alasan singkat, lalu tanyakan pilihan tim. Tulis hanya yang sudah disetujui.
3. Saat mengusulkan dataset atau paper, sertakan link sumber asli dan lisensi. Jangan mengarang.
4. Di akhir, tampilkan checklist Fase 0 dan tandai mana yang sudah selesai.
