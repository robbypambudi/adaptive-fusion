# Fase 0: Setup Template

**Tujuan:** tim sepakat tentang apa yang diteliti sebelum ada kode.

## Langkah
1. `make setup` lalu `make test` (harus lolos).
2. Tulis ide bebas di `docs/ide.md`, lalu susun menjadi `docs/research-charter.md` bersama tim. AI boleh memberi usulan, tapi keputusan di tangan tim.
3. Bagi tugas anggota tim (tabel "Tim" di charter).

## Checklist selesai
- [ ] `make test` lolos di komputer setiap anggota
- [ ] Charter terisi: pertanyaan, hipotesis, dataset, baseline, metrik utama
- [ ] Metrik utama dipilih **sebelum** melihat hasil
